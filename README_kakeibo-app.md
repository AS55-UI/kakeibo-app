# 家計簿管理アプリ
 
## 概要
Laravelを使用して作成した家計簿管理アプリです。
ログイン後に支出の登録・編集・削除ができます。
 
## 機能
- ユーザー登録・ログイン・ログアウト
- 支出の登録
- 一覧表示
- 編集・更新
- 削除
- 入力バリデーション
 
## 使用技術
- Laravel
- MySQL
- Blade
- Vite
- PHP
 
## 動作方法
1. git clone
2. composer install
3. cp .env.example .env
4. php artisan key:generate
5. php artisan migrate
6. npm install
7. npm run dev
8. php artisan serve
