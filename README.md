# 家計簿アプリ(Laravel)

## 概要
日々の支出を簡単に記録・管理できる家計簿アプリです。  
ログイン後、自分の支出を登録し、一覧で確認・編集・削除することができます。
また、検索・並び替え・集計機能により、効率的にデータを管理できます。

---

## どんなことができるか

- ユーザー登録、ログイン、ログアウト
- 支出の登録・一覧表示・詳細表示
- 支出の編集・更新・削除
- 検索機能（年月・日付・カテゴリで絞り込み）
- 並び替え機能（新しい順・古い順）
- ページネーション機能（一覧ページ分割して表示）
- 月ごとの合計金額の表示
- カテゴリ別集計表示
- CSVダウンロード機能
- 予算管理機能（予算と実績の比較）
- ログインユーザーごとのデータ表示制御（他ユーザーのデータは表示不可）

---

## 使い方（流れ）

1. ユーザーの新規登録
2. ログイン
3. 支出を新しく登録
4. 一覧画面で内容を確認
5. 必要に応じて編集・削除

## 実装で意識した点
- 入力内容に対してバリデーションを設定し、不正な入力を防止
- 編集時に入力内容が保持されるように実装（old関数）
- ログインユーザーのみ操作できるように制御
- 検索機能では複数条件（年月・日付・カテゴリ）を組み合わせて絞り込めるように実装
- 日付検索を優先するロジックを実装し、ユーザーの意図に沿った結果を表示
- 並び替え時に同一日付でも順序が崩れないようにIDを用いて安定した並び順を実現
- ページネーションを導入し、大量データでも見やすく表示できるように改善
- 月ごとの合計はDBの集計処理（GROUP BY）を用いて効率的に取得
- 非表示データや不正アクセスに対するセキュリティ考慮（404・403・419対応）

## 動作方法

以下の手順でローカル環境で動作確認ができます。

1. フロントのビルドを行います
 ```npm run dev``` を実行
 
2. ローカルサーバーを起動します
```php artisan serve``` を実行
 
その後、
http://127.0.0.1:8000 にアクセスするとアプリが起動します。
